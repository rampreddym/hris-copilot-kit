# FICTIONAL SAMPLE: not real vendor release notes

These invented notes exist only to test the Release Note Triage skill. They do not describe any real Oracle or Workday release.

## Core HR
- **Redesigned Employee Profile Page.** On by default. The person profile page uses a new card layout. Custom fields added to the old page must be re-added to the new layout.
- **Bulk Assignment Changes from Spreadsheet.** Opt-in. Administrators can upload a spreadsheet to change job, location or manager for many workers at once.

## Absence
- **Accrual Rounding Change.** On by default. Accrual balances now round to two decimal places instead of four.

## Compensation
- **AI Salary Recommendation Assistant.** Opt-in. Suggests merit increases for managers using performance rating, compa-ratio and market data.

## Integrations
- **Legacy SOAP Worker Service Deprecated.** The SOAP worker web service will be removed in the release after next. Use the REST Workers API instead.

## Recruiting
- **Generative Job Description Writer.** On by default for administrators. Drafts job descriptions from a job title and level.

## Learning
- **Course Catalog Search Improvements.** On by default. Better relevance ranking in learner search.
